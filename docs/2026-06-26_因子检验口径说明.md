# 因子检验口径说明

本文档记录因子库单因子检验模块的主要口径，适用于线上页面 `https://fifamy.github.io/factor-lib/` 中的“因子检验摘要”。

## 样本与调仓

- 样本空间沿用 Word 股票池规则，不按 `is_active_latest` 做历史幸存者过滤。
- 月末截面调仓，组合收益使用下一相邻月收益。
- Top30、10 分组和 IC 统计均基于同一历史样本口径。

## 交易成本

- 10 分组与 TopN 回测沿用项目回测成本口径。
- 当前分组回测成本为单边 `0.2%`，多空组合为高分组收益减低分组收益。
- 页面中的成本敏感性为前端估算项：以当前 Top30 月收益序列和摘要中的月均换手为基础，按 `0bp / 10bp / 20bp / 50bp` 单边成本重估年化收益、夏普、回撤和月度胜率。
- 成本敏感性用于判断因子对交易摩擦的敏感程度，不替代逐月真实换手明细回测。

## 主要指标

- `RankIC均值`：因子截面排序与未来收益排序的 Spearman 相关均值。
- `IC_IR`：RankIC 均值除以 RankIC 标准差，并按月频年化。
- `IC胜率`：RankIC 为正的月份占比。
- `月度胜率`：组合月度收益为正的月份占比。
- `10组单调性`：G1 到 G10 年化收益与组别序号的 Spearman 秩相关。
- `分层 IC`：按全市场、行业、市值、流动性分层分别计算 RankIC。
- `分层组合收益`：按全市场、行业、市值、流动性分层，在每个分层内部取 Top/Bottom 组合并计算多空收益。
- `分层组合收益图`：按多空年化展示各分层收益强弱，绿色表示该分层 Top 相对 Bottom 占优，红色表示反向；悬停时同步查看多空回撤、胜率、换手和样本月数。
- `样本外 / 滚动`：展示全样本、近 5 年、近 3 年、训练、验证、测试，以及 36 个月滚动 IC_IR。

## 基准与超额

- 若 `frontend/data/benchmarks.parquet` 可用，摘要表会使用基准净值计算 Top30 超额收益。
- 优先使用 `EW` 等权全市场基准；若缺失则回退到 `HS300`，再回退到文件中的第一个基准。
- `top30_excess_ann_return` 为 Top30 月度收益减基准月度收益后的年化收益。
- `top30_excess_max_drawdown` 为月度超额收益序列对应的最大回撤。
- 单因子页面支持在 `沪深300 / 中证500 / 中证800` 间切换基准，并用已发布的月收益和基准净值在前端重算超额年化与超额回撤。
- 排行榜中的超额年化和超额回撤仍使用离线摘要中的默认基准口径，便于跨因子排序保持一致。

## 分层口径

- 行业分层使用当前可用的申万一级行业映射。
- 市值和流动性分层按月度截面计算，避免使用最新快照造成前视。
- 分层组合收益使用 1M 前瞻收益，在每个分层内按因子得分排序，Top 和 Bottom 默认各取 30% 股票，股票数不足阈值的分层不展示。
- 分层组合收益的成本按 Top/Bottom 实际持仓变化估算换手，并沿用单边 `0.2%` 成本；多空收益为 Top 组合收益减 Bottom 组合收益。
- 当前页面展示分层组合收益摘要，不导出分层组合逐月净值，避免快照数据量过大。
- 分层组合收益图只展示多空年化绝对值最高的前若干分层，用于快速定位收益主要来自哪些市值、流动性或行业分层；最终判断仍应回到表格中的回撤、胜率、换手和样本月数。

## 多因子检验

- 多因子检验跟随“多因子合成”编辑器的当前配置，包括因子方向、分数口径、权重、阈值过滤、TopN、组合约束和回测区间。
- 合成分数为各因子方向化得分按权重加总，RankIC、IC_IR、前瞻期衰减和 10 组收益均基于该合成分数重新计算。
- 组合表现沿用多因子合成的 TopN 回测路径，行业中性约束会影响持仓和组合收益，但不改变合成分数 RankIC 的排序检验含义。
- 组合内相关性用于识别因子冗余。若组合内多个因子相关性较高，即使收益表现较好，也应关注是否只是重复暴露于同一类信号。
- 与最佳单因子对比用于判断多因子是否带来增量。若多因子 RankIC、IC_IR 或回撤表现没有优于组合内较强单因子，说明合成权重仍需复核。
- 已发布组合和我的组合可以通过“检验”按钮载入当前合成页，使用同一套多因子检验口径实时复核。
- 本阶段不做自动组合挖掘、ICIR 自动加权或机器学习模型训练，避免把检验页面变成过拟合搜索工具。

## 组合归因与剔除实验

- 组合归因与剔除实验采用留一剔除方法：先计算完整多因子组合，再逐个剔除一个因子，并用相同的 TopN、组合约束、回测区间、方向、权重、阈值和分数口径重算检验指标。
- 表中所有 `Δ` 指标均表示 `完整组合 - 剔除后组合`。正数通常说明该因子加入后改善了组合表现，负数通常说明剔除后更好。
- `ΔRankIC` 和 `ΔIC_IR` 用于判断该因子是否提升合成分数的排序信息和稳定性。
- `ΔTopN年化` 用于判断该因子是否提升实际 TopN 组合收益。
- `Δ最大回撤` 为完整组合最大回撤减剔除后最大回撤。由于最大回撤通常为负值，正数表示完整组合回撤压力更低，负数表示剔除后回撤更好。
- `Δ10组单调性` 和 `Δ多空年化` 用于判断该因子是否强化高低分组之间的经济含义。
- 判断标签中，`增益` 表示剔除后核心指标变差，说明该因子有边际贡献；`冗余` 表示剔除前后变化较小；`拖累` 表示剔除后核心指标改善，需要检查该因子的方向、权重、阈值或适用样本。
- 剔除实验是边际贡献提示，不是 Shapley 归因，也不会自动重新优化剩余因子的权重。若组合内因子高度相关，剔除结果可能受因子替代关系影响，应结合组合内相关性和样本切片共同判断。

## 多因子参数敏感性

- 多因子参数敏感性用于检查组合结论是否依赖特定 TopN、组合约束或精确权重，是稳健性复核工具，不用于自动寻找最优参数。
- `TopN 敏感性` 使用相同因子方向、权重、阈值和回测区间，分别比较 `Top10 / Top30 / Top50`。若只有单一 TopN 有效，应降低组合结论权重。
- `约束敏感性` 比较无约束等权和行业中性约束。若行业约束改变后 RankIC、IC_IR 或收益显著转弱，说明组合可能依赖行业暴露或集中持仓。
- `权重扰动敏感性` 对绝对权重最大的核心因子做 `+20% / -20%` 轻微扰动，并保持总绝对权重规模一致。若轻微调权后结论反转，说明组合对精确权重较敏感。
- 判断标签中，`稳健` 表示关键指标未明显恶化；`敏感` 表示 IC_IR、收益或回撤对某类参数变化较敏感；`需复核` 表示 RankIC 或收益方向在参数扰动下反转，或该参数场景存在关键指标缺失，需要先检查持仓、收益和样本覆盖。

## 多因子相关性 / 拥挤度诊断

- 多因子相关性 / 拥挤度诊断用于检查组合是否过度依赖相近因子、热门交易或低容量股票，是风险复核工具，不直接替代 RankIC、收益和样本外检验。
- 相关性诊断复用组合内因子相关矩阵，展示最高相关性、平均绝对相关性、高相关因子对数量和有效因子数估算。有效因子数估算采用 `N / (1 + (N - 1) * 平均绝对相关性)`，只用于提示冗余程度，不是严格统计检验。
- 最高相关性低于 `0.5` 通常较低，`0.5-0.7` 需要观察，`0.7-0.85` 偏高，`0.85` 以上需重点检查是否重复表达同一类信号。
- 拥挤度诊断基于当前 TopN 最新持仓和历史调仓路径，展示持仓月均换手、中位成交额、中位市值、前三行业集中度和低流动性占比。
- 低流动性占比是当前持仓中成交额和市值同时低于组合中位数的股票占比。该比例越高，组合越容易受到容量、滑点和交易可实现性约束。
- 高拥挤因子暴露来自 `ABTURN`、`TURNPCTL`、`HIGHMOMTURN`、`TURN20D120` 等拥挤度相关因子的最新截面得分。若这些暴露偏高，说明当前组合可能集中在异常换手、短长换手升高或高动量高换手股票上。
- 若相关性风险和拥挤度风险同时偏高，应优先复核因子权重、过滤阈值、行业约束和换手成本，再判断组合是否适合发布或实盘跟踪。

## 多因子组合排行榜

- 多因子组合排行榜用于横向比较已发布组合和我的组合，不做 148 个因子的自动组合搜索。
- 排行榜复用单个多因子检验的 `RankIC`、`IC_IR`、`TopN` 回测、10 组单调性、组合内相关性和最佳单因子对比口径。
- 综合分只用于排序提示，综合考虑 `IC_IR`、`RankIC`、年化收益、10 组单调性、最大回撤、组合内最高相关性和相对最佳单因子的 IC_IR 增益，不代表最终投资结论。
- 若样本月数不足 36、组合内最高相关性过高，或相对最佳单因子没有增益，应降低该组合排名结果的解释权重。

## 经验阈值

页面中的颜色和图标为经验参考，不是硬性标准。

- `|RankIC| < 1%` 通常偏弱，`1%-3%` 有一定信息，`3%-5%` 较有价值，`>5%` 较强，`>10%` 需要核查数据泄露、样本偏差或过拟合。
- `IC_IR < 0.3` 不稳定，`0.3-0.5` 初步可用，`0.5-1.0` 稳定性较好，`>1.0` 较强，`>2.0` 需要核查口径。
- `IC胜率 / 月度胜率 55%-60%` 可接受，`>60%` 较稳定。
- `样本月数 <36` 参考意义有限，`36-60` 可初步观察，`>60` 更适合做稳健性判断。
- 页面出现“样本不足”提示时，表示前瞻期 RankIC、10 分组、分层 IC 或分层组合收益中存在低于 36 个月的统计项。此时不宜只凭单项高收益或高 IC 下结论，应降低结论权重，并结合滚动、样本外和不同分层结果交叉验证。
